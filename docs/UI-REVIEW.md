## 发现并修正

| 位置 | 问题 | 处理 |
| --- | --- | --- |
| 首页 | 开发样例不能冒充用户已有申请 | 首次进入为空状态，实际填写后才有申请卡片；进度按必填且通过校验的资料统计 |
| 首页 / 参考件入口 | 多份申请时直接打开第一份会选错人 | 先显示已生成申请列表，由用户选择 |
| 步骤条 | 连线穿过圆点；320px 下标题断在不合适的位置 | 圆点遮住连线；在“与”之后允许语义换行，名称完整保留；03 不显示工作步骤 |
| 问卷 | “必填”与“没有的可留空”提示矛盾 | 必填项与可选项使用不同提示；表格抬头明确无栏号，不显示内部 H01/H02 编号 |
| 问卷 | 错误只能在生成 PDF 时发现 | 失焦校验当前字段，提交校验整步；汇总可跳转输入，汉字原值保留供修改 |
| 家人 / 我的 | 通用列表规则把第一个图标拉宽，文字列不齐 | 图标保持固定宽度，只让内容列伸展 |
| 家人 | 自动覆盖申请资料难以察觉 | 复制必须选来源、目标和项目再确认；不复制姓名、护照和税号，已有申请不跟随家人编辑自动改变 |
| 家人 | 说明卡反复出现会占用空间 | 首次展示后记录已看过，可以当场关闭，后续进入不再展示 |
| 预览 | A4 须知缩到手机宽度后难读 | 增加可展开的须知文字版；保留完整 PDF 页面、双指缩放和有标签的缩放按钮 |
| 预览 | 下载和翻页争抢底部主操作 | 下载在右上；底部固定上一页、页码页名、下一页；首尾按钮禁用 |
| 资料状态 | 编辑后旧 PDF 仍显示有效会误导 | 修改资料取消已生成状态；材料勾选独立保存；再次生成使用新资料 |
| 备份 | 损坏文件、覆盖和清除可能导致资料丢失 | 版本和结构校验；导入替换与清除均二次确认；坏备份不改现有资料，无法读取的本机记录不自动覆盖 |

## 九项检查

1. **间距**：页面 16px、卡片 20/24px，列表图标列固定；按钮和可点帮助均至少 44px。
2. **颜色**：使用 v2 的 `#F7F0EA`、`#FBF7F3`、`#B5532A`、`#6B5F57` 和规定的输入、错误、通过色值。没有从参考图重新采浅色。
3. **图标**：统一 SVG 线条，蓝色主体与赤陶点缀，无 emoji、铃铛或伪状态栏。
4. **文案**：实际资料状态、居留到期日期、当前开放类型；不用宣传语，不凭空承诺资格、费用或税号官方核验。
5. **字体**：本机系统字体，正文与输入 16px、说明 13px，页码和百分比使用等宽数字。
6. **布局**：选申请是搜索加分组列表；手机问卷单列，宽屏双列；参考件可以平移缩放。
7. **细节**：可见输入边框、键盘焦点、原生模态对话框、文字错误、材料标签和禁用首尾翻页。
8. **内容视觉**：真实生成的表格页面是主要视觉，没有装饰性占位图或虚假数据卡片。
9. **动效**：只保留短颜色反馈，尊重减少动态效果偏好；没有循环动效、跳动缩放或布局动画。

v2 明确要求的圆角卡片、胶囊控件、暖色单层阴影和双色图标予以保留；不套用 unslop 的通用灰色后台风格。
