## 两个已复现缺陷

### 搜索选项误处理中文输入法确认

`SearchSelect.tsx` 将组合输入期间的 Enter 当成选项确认，导致搜索面板关闭、草稿中的国家值被意外替换。可在手机底部面板和桌面浮层复现。

修复：触发按钮和搜索框均跳过 `isComposing` 或键码 229 的键盘事件；正常回车仍选择选项，方向键逻辑保持原样。键码 229 用于兼容部分输入法确认事件。

### 重复点击当前参考页后加载提示不消失

`Preview.tsx` 的 `go()` 总是设置“正在显示页面…”，但点击当前页时页码没有改变，渲染 effect 不会重新运行，因此不会清除状态。当前文件页签和桌面当前页缩略图都受影响。

修复：仍允许同页点击重置缩放，页码相同时不设置新的加载状态；切换其他页继续正常渲染。

## 复现与验证入口

`npx playwright test ui-regressions.spec.ts --reporter=list`：修复前四项测试全部失败，分别证明 390px / 1280px 下的输入法误选与加载状态卡住；修复后用于回归。已有视觉测试以只比较模式运行，不更新基准。完整结果记录于 HANDOFF.md。

浏览器合成组合输入事件验证的是事件处理分支；真实手机输入法仍可在用户试用时补充确认。
