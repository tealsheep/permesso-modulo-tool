# 界面设计说明 v3（暖色新拟物）

- 版本：v3 · 2026-11-06 · 维护者：Claude
- 依据：D37、D38（交互部分）、D39、D40（页面结构）、D41、**D42（视觉基准）**。
- **视觉基准（最高优先级）**：`designs/soft-neumorphism/`。`index.html` 是用户认可的样式原型，`mobile-preview.png`、`error-preview.png`、`desktop-preview.png` 是基准截图。本文第 2 节的数值从这个原型提取；两者不一致时以原型为准，并更新本文。
- 页面结构和交互仍按第 3 节（来自 v2）。旧参考图 `docs/design/2026-11-05_ui-reference.webp` 只作页面布局参考，**颜色和阴影不再以它为准**。它含个人资料，D51 起移出仓库，由用户私下保管。

---

## 1. 设计原则

1. **温暖、让人放心**：暖米色同色系的新拟物质感（凸起和凹陷），赤陶色只做强调。用户多半对填官方表格感到紧张。
2. **一屏只有一个主操作**：底部一个胶囊形主按钮。
3. **能扩展**：申请类型以后约 30 种，选申请一律用列表 + 搜索。
4. **始终能对上纸质表格**：每个字段都显示栏号和意大利文（D3）。
5. **错误要说清楚哪一格、怎么改**，并尽量给出一键修正。
6. **不写宣传语**：卡片上写真实状态，不写"让填表更高效"之类的话。

## 2. 视觉规格 v3（从 `designs/soft-neumorphism/index.html` 提取）

### 2.1 样式变量（唯一来源）

代码里所有颜色、阴影、圆角**只能**用下面这些变量，放在一个统一的样式变量文件里（建议 `src/ui/tokens.css`）。页面和组件里不得出现新的颜色值、阴影值或圆角值；确实需要新值时先问用户，同意后加进这张表和变量文件。

| 变量 | 值 | 用在哪里 |
|---|---|---|
| `--surface` | `#eee8df` | 页面、卡片、按钮、输入框的底色（全部同色） |
| `--page-outer` | `#e5e0d8` | 宽屏时手机框外面的背景 |
| `--ink` | `#342d28` | 标题、正文、输入内容 |
| `--muted` | `#71665d` | 栏号、提示、未开始的步骤、次要图标 |
| `--accent` | `#ac4e2e` | 主按钮底色、当前步骤、完成步骤、聚焦边框、分节标题图标 |
| `--accent-hover` | `#994327` | 主按钮悬停、当前步骤名和电脑当前项文字（D44） |
| `--on-accent` | `#fff7ee` | 主按钮、完成步骤上的文字和图标 |
| `--error` | `#a73930` | 出错的边框、错误文字和图标、一键修正链接 |
| `--line` | `#d3c8bc` | 步骤条连线、列表分隔线 |
| `--date-sep` | `#9e8e7c` | 日期三格之间的"/" |
| `--ok` | `#2f6b45` | 校验通过的小字和对勾（原型里没有这种状态，Claude 补充；在 `--surface` 上约 5.6:1） |

### 2.2 阴影（光源固定在左上）

| 变量 | 值 | 用在哪里 |
|---|---|---|
| `--panel` | `8px 8px 24px #ddd6cd, -8px -8px 24px #fbf6ef` | 大面板：分节卡片、弹窗 |
| `--raised` | `5px 5px 12px #d8d1c8, -5px -5px 12px #fffbf5` | 凸起：返回按钮、次要按钮、(?) 按钮、快捷操作、选中的分段 |
| `--raised-xs` | `2px 2px 5px #d5cec5, -2px -2px 5px #fffaf3` | 小凸起：步骤圆点（未开始） |
| `--inset` | `inset 2px 2px 5px #dcd5cc, inset -2px -2px 5px #f9f5ef` | 凹陷：输入框、当前步骤圆点、按下状态 |
| `--primary-shadow` | `4px 5px 10px #c5ad9b, -3px -3px 8px #fff8ee` | 主按钮 |
| `--primary-pressed` | `1px 2px 4px #bfa48f` | 主按钮按下（同时 `translateY(1px)`） |
| `--backdrop` | `#30251e55` | 弹窗背后的遮罩 |

- **按下状态**：凸起的元素按下时换成 `--inset`（由凸变凹）。
- 不用渐变，不用彩色发光。

### 2.4 组件外观

- **输入框**：底色 `--surface` + `--inset`，1px `--line` 描边（D44）。聚焦时边框变 `--accent`，出错时边框变 `--error`，**都不加光晕、不改变尺寸**。
- **可搜索的选择框**（§3.9）：外观和输入框一样，右边放大镜或箭头图标用 `--muted`。
- **错误提示**：输入框边框变 `--error`，下方一行 `--error` 色小字，前面一个小警告图标。一键修正是 `--error` 色带下划线的文字按钮（如"改成 ZHEJIANG"），可点区域至少 44 高。**不用整块的浅红底色。**
- **步骤条**：圆点 30px；未开始用 `--raised-xs` 和 `--muted` 数字；当前用 `--inset`，步骤名变 `--accent-hover` 加粗（D44；圆点仍为 `--accent`）；已完成是 `--accent` 实心圆加白色对勾。连线 1px `--line`，走到当前步骤的线变 `--accent`。
- **分节卡片**：`--panel`，没有边框；标题行左边是 `--accent` 色线条图标（不加凸起的图标底座），右边 (?) 按钮。
- **主按钮**：`--accent` 实底，`--on-accent` 字，`--primary-shadow`；悬停 `--accent-hover`；按下用 `--primary-pressed`。
- **次要按钮 / 圆形按钮**：`--surface` + `--raised`，按下换 `--inset`。
- **弹窗**：`--surface` + `--panel`，圆角 24，背后 `--backdrop`。
- **键盘焦点**：按钮和链接 `outline: 2px solid var(--accent); outline-offset: 4px`。
- **动效**：只在用户没有关闭动效时，用 0.15s 过渡底色、边框、位移。

### 2.5 可读性检查与 D44 已授权调整

以下是最初发现的问题，已由 D44 授权下列定向调整；其他视觉仍按 D42，新的样式变更仍需用户决定：

1. 普通状态的输入框边框是透明的，边界只靠很浅的内阴影。在强光、高对比度模式下是否还找得到输入框。
2. 栏号、提示 11px、步骤名 10px 偏小。系统字体放大后是否仍然可读、不重叠。
3. `--accent` 作为小号文字（当前步骤名）在 `--surface` 上的对比度约 4.4:1，略低于 4.5:1。

**用户决定（D44，2026-11-06）**：
1. 输入框普通状态加 1px `--line` 描边；
2. 小字改用 rem，跟随系统字号；
3. 当前步骤名加粗，文字颜色改用现有的 `--accent-hover`（约 5.3:1）。

实现换算：根字号100%，以浏览器默认16px为基准，11px→0.6875rem、10px→0.625rem；默认视觉大小不变。步骤名允许在本步骤宽度内换行，200% 字号验证五 / 六步及电脑列表日期。强光和真实手机系统字号仍需实机观察，浏览器仿真不替代实机结论。

**不做**：状态栏（9:41、信号、电量）、通知铃铛。

## 3. 页面与交互

### 3.1 导航栏（首页以外）
- 左边是圆形返回按钮（`aria-label="返回"`），中间是标题，右边留给页面操作，比如参考件页的"下载 PDF"。

### 3.2 首页：按人分组的申请列表（D43）
- **顶部**：应用图标 +"居留填表助手"。**没有铃铛**。下面大标题"我的申请"，旁边或下方是主按钮"＋ 新建申请"。
- **筛选**：`全部 / 进行中 / 已生成`（≤6 项胶囊）。申请多于 5 份时出现**姓名搜索框**（外观同输入框）。
- **列表**：**按人分组**。
  - 分组标题：姓名 + 关系（本人 / 配偶 / 子女 / 其他），右边文字按钮"编辑资料"。
  - 每行一份申请：类型（中文 + 意大利文小字）、进度（百分比或"已完成"）、居留到期日、状态（进行中 / 已生成），右边箭头。点整行进入**申请页**（§3.2a）。
  - 带孩子一起办的申请，在主申请人那一行写"带陈乐乐"，孩子不单独成行。
- **空状态**：还没有申请时，一句说明 +"新建申请"按钮。
- **不再有快捷操作**（家人资料 / 材料清单 / 参考件 / 常见问题），这些都放进申请页或"我的"。
- **导航**：手机底部导航只有**首页 / 我的**；电脑端见 §3.10。

### 3.2a 申请页（每份申请一页，D43）
- 标题：申请类型；小字：申请人（及带的家人）+ 意大利文类型 + 代码。
- 进度：已完成 X / Y 项、下一节是什么。
- 主按钮"继续填写"（已生成的申请改为"查看参考件"）；两个次要按钮"参考件""材料清单"。
- "要交的钱"：每张缴费单分别列出（主申请人、每个未满 14 岁的孩子），加邮局邮寄费和印花税票。
- 底部文字按钮："复制为新申请"（例如明年续签时沿用）、"删除这份申请"（二次确认）。

### 3.2b 新建申请：先选"给谁办"（D43）
- 第一步：列出已保存的人（姓名 + 关系），加一项"新的人"。选已有的人时，**自动带出这个人最近一次申请里的个人资料**（姓名、护照、出生信息、住址等），用户只需改有变化的部分。
- 第二步才是 §3.3 选申请类型。

### 3.3 选申请
- D46：有 `alsoInGroups` 的类型在主分组及附加分组同时出现；学习类24 /31同时列在续签和第一次申请。进入后默认采用所点分组支持的办理方式，在申请信息中仍可修改。搜索结果按唯一类型展示，匹配分组名称时优先展示该组；统计不重复计数。
- 交互同样式 F，换成本风格的外观：
  - 标题"你要办什么？"。
  - **搜索框**：外观同输入框（§2.4，凹槽、`--line` 细边），带放大镜。中文名、意大利文名、分组名都能搜，输入时实时过滤。搜不到时给出提示。
  - 一行"不确定选哪个？回答 3 个问题帮你选"。
  - **分组卡片**：每组一张卡片，组标题左边中文、右边意大利文（续签 RINNOVO / 第一次申请 RILASCIO / 更新、补发、转换），分组来自 `application-types.json` 的 `group`；有 `alsoInGroups` 的类型也同时列在那些分组里（D46：学习类在续签和第一次申请都显示，从哪组点进去就默认哪种办理方式）。用户 2026-11-06 试用后补充：分组名用 14px / 500 的 `--muted` 次要标签，申请项目用 16px / 600 的 `--ink`，明确区分分类与可选内容。卡片里每行主文字是中文名，次要文字是意大利文名，右边箭头。未支持的类型灰字，右边写"即将支持"，点了没反应。
  - 最下面一行"要直接去 Questura 办的情况"。

### 3.4 填表：5 步步骤条（D40）
- 页面顶部是步骤条：**申请信息 / 个人与护照 / 住址 / 工作与收入 / 家属与提交**。
  - 外观见 §2.4 步骤条（已完成实心、当前凹陷、未开始小凸起）。
  - 不需要 Modulo 2 的申请（如更新长居卡）**不显示**"工作与收入"，只剩 4 步。
  - 点已完成的步骤可以回去修改。
- 每一步里有若干**分节卡片**，对应表格的一节或一组相关字段：
  - 卡片标题行：左边双色图标 + 标题（如"姓名""出生城市""税号"），右边 (?) 按钮。点 (?) 弹出说明：在哪里找、怎么写、对应纸质表哪一栏。
  - **字段**从上到下依次是：
    1. 中文标签
    2. 栏号和意大利文小字（如"第 3 栏 · COGNOME"）
    3. 输入框
    4. 提示（灰字，**在输入框下方，不放侧栏**）
  - 两个很短的字段（如姓、名）可以左边标签、右边输入框排成两行，但栏号和意大利文仍要显示。
- **校验**：
  - 离开输入框时校验这一格，出错时按 §2.4 错误提示显示：边框变红，下方一行红字写清问题；能一键修正的，给一个带下划线的文字按钮（如"改成 ZHEJIANG"）。
  - 点"保存并下一步"时校验整步。有错时停在这一步，顶部显示"有 N 处需要修改"，点每一条跳到对应输入框。
  - 通过提示：输入框下方一行 `--ok` 色小字，前面一个小对勾图标，不加底色。如"已核对：与你的姓名、生日、性别一致"。
- **底部按钮**：左边"上一步"（次要按钮，凸起），右边"保存并下一步"（主按钮，更宽）。最后一步的主按钮叫"生成参考件"。

### 3.5 人的资料（不再有单独页面，D43）
- **没有"家人资料"页面和导航项**。人的资料从三个地方进入：
  1. 新建申请第一步"给谁办"（§3.2b）。
  2. 首页分组标题旁的"编辑资料"：编辑姓名、关系、出生信息、护照等个人资料。改动不会自动改已有的申请，保存时提示"要不要同步到进行中的申请"。
  3. 问卷"家属与提交"一步里勾选"带配偶 / 带子女"：从已保存的人里选，也可以当场"添加一个人"。
- **复制共同信息**：在问卷"住址"一步顶部给一行"和某人住在一起？复制住址、电话"，选人 → 勾选要复制的项（住址、电话、邮箱、受理地）→ 确认。姓名、护照、税号不复制（D15）。
- 关系选择（本人 / 配偶 / 子女 / 其他）用 ≤6 项胶囊单选，不用下拉框。

### 3.6 参考件（D37）
- 导航栏右边是"下载 PDF"。
- 顶部是胶囊形分段标签：须知 / Modulo 1 / Modulo 2 / 缴费单 / 材料。点标签跳到该文件的第 1 页。
- 中间是页面，和原表一模一样，可以双指缩放。页面本身是白底直角，外面有卡片阴影。
- 底部是翻页栏："上一页"（次要按钮）/ 页码和页名 / "下一页"（主按钮）。到头或到尾时对应按钮置灰。
- 须知内容见 SPEC §4（含印花税票位置）。**不做逐栏对照**（D39）。

### 3.7 材料清单
- 按申请分组的卡片。每项是一个圆形勾选框，主文字中文，次要文字意大利文。`basis` 为 `common` 的条目加一个浅色胶囊标签"常见要求，以当地 Questura 为准"。
- 顶部用进度环或文字显示"已准备 X / N"。

### 3.8 我的
- 卡片列表："常见问题""导出备份文件""导入备份文件""清除本机所有资料"（红字，需要二次确认），以及"关于和免责声明"。
- 顶部一行说明："资料只保存在这台设备的浏览器里。换设备或清理浏览器前，请先导出备份。"

### 3.10 电脑端与平板布局（D43）

参考原型画布 H 行（https://claude.ai/artifact/NJqkAEseTUwardg6Dko7ZU）。视觉不变（D42），只改版面。

| 宽度 | 布局 |
|---|---|
| ≥ 1024px | 三栏（见下） |
| 768–1023px | 两栏：去掉右侧栏，右侧内容收进申请页或 (?) 面板 |
| < 768px | 手机单栏（现有布局） |

- **全局**：左侧栏宽约 232px，放应用名、导航（我的申请 / 我的）、底部"资料只保存在这台电脑的浏览器里"。手机底部导航在这个宽度下隐藏。
- **首页**：中间是按人分组的申请列表，做成表格式的行（申请 / 进度 / 居留到期 / 状态），顶部是搜索、筛选和"新建申请"；右侧栏约 360px，显示**当前选中那份申请的申请页内容**（§3.2a）。点不同的行，右侧跟着换；当前行用凹陷底色 + `--accent` 细边标出。
- **填表**：
  - 左侧栏是**竖向步骤**，当前步骤展开显示它的分节，点分节跳到对应位置。
  - 中间是表单，内容最宽约 720px；短字段（姓 / 名、日期 / 性别、省 / 邮编等）两列并排。底部"上一步 / 保存并下一步"靠右。
  - 右侧栏约 360px，分两块：**"对照纸质表格"**，用参考件同一套渲染显示当前字段所在的纸质表页面缩略图，并高亮正在填的格子；**字段说明**，直接显示当前字段的 `help` 和所在分节的说明，不用点 (?)。
- **参考件**：中间显示大页面；左侧栏显示所有页的缩略图列表（须知 / Modulo 1 各页 / Modulo 2 各页 / 缴费单 / 材料），点缩略图跳页；底部翻页栏保留。
- **截图基准**：新增 1280px 宽的首页、填表、参考件三张基准截图；手机端基准不受影响（首页因 §3.2 版面变化另行更新）。

### 3.9 组件替换（D41）

借用 Radix 无样式组件（`@radix-ui/react-dialog`、`@radix-ui/react-popover` 等，必要时加 `cmdk` 做搜索列表），**样式用本文第 2 节的规格**，不引入 Tailwind，也不用 shadcn 的默认黑白主题。所有依赖随网站打包，不走 CDN（D8）。

#### 日期输入：三格"日 / 月 / 年"
- 用于所有日期字段：出生日期、居留到期、护照有效期、住房证明日期、合同日期等。
- **外观**：三个独立输入框，宽度分别对应 2 位、2 位、4 位，中间用赤陶色的"/"分隔，和纸质表格的 gg / mm / aaaa 一致。每格下方用小字标"日""月""年"。
- **输入**：
  - 数字键盘（`inputmode="numeric"`），只接受数字。
  - 一格填满自动跳到下一格；空格里按退格，回到上一格。
  - 粘贴 `31/12/2026`、`31.12.2026` 或 `2026-12-31` 时，自动拆进三格。
  - 不弹日历。打字比翻日历快，选出生日期时尤其明显。
- **存储**：三格都填好且是有效日期时，存为 ISO `YYYY-MM-DD`；没填完时，只在界面里保留已输入的内容，不写进资料。
- **校验**（离开这组输入框时）：
  - 没填完："请把日、月、年都填上"
  - 日期不存在（如 31/02）："这个日期不存在，请检查"
  - 出生日期晚于今天："出生日期不能晚于今天"
  - 证件已过期：沿用现有的过期提示
- **无障碍**：整组用 `fieldset` + `legend`（字段标签），三个输入框分别加 `aria-label="日"` / `"月"` / `"年"`；错误信息用 `aria-describedby` 关联到整组。

#### 长列表选择：可搜索的选择面板
- **用在哪里**：选项超过 12 个的字段，包括国家（出生国、国籍）、省份（Questura 省、住址省等）、申请类型代码、其他证件、签发机关。
- **少于等于 6 个选项的**（性别、婚姻状况、证件种类、是 / 否等）不用这个组件，继续用胶囊按钮或单选。
- **选择框外观**：和输入框完全一样（§2.4）。显示已选项，如"中国 · CHN""Milano · MI"；没选时显示 `--muted` 色"请选择"；右边放大镜图标。
- **打开后**：
  - 手机：从底部弹出的面板，约占屏幕 85% 高，顶部有标题（字段名）和关闭按钮。
  - 宽屏：在选择框下方弹出浮层。
  - 打开后光标自动在搜索框里。
- **搜索**：同时匹配中文名、意大利文名和代码；不区分大小写，忽略重音（输入 `forli` 能找到 `FORLÌ`）。
- **常用项置顶**：国家把"中国 CHN""意大利 ITA"放在最上面一组"常用"；省份把用户已经填过的省份放在最上面。
- **列表行**：主文字中文名（没有中文的显示意大利文名），右边小字显示代码；已选项右边打勾。每行至少 48px 高。
- **搜不到时**："没有找到，可以试试意大利文名或代码"。
- **键盘**：上下键移动，回车选中，Esc 关闭（Radix / cmdk 自带）。

#### (?) 说明：底部弹出的半屏面板
- 点分节卡片的 (?) 时，手机上从底部弹出面板，宽屏显示居中对话框。
- 面板内容：
  - 标题：分节名称
  - 先显示 `sections` 的说明，再列出该分节里有 `help` 的字段说明，每条前面加粗字段名
- **关闭方式**：右上角关闭按钮、点面板外面、按 Esc、手机上向下滑。
- 打开时焦点移进面板，关闭后回到 (?) 按钮（Radix Dialog 自带）。
- 面板外观同 §2.4 弹窗：`--surface` + `--panel`，手机上只有上方两个角圆角 24，宽屏四角 24；背后 `--backdrop`。可搜索的选择面板也用同样的外观。

## 4. 文案规则
- 一律用"你"，不用"您"。
- 句子短，说具体的事；卡片上写真实状态，不写宣传语。
- 意大利文术语保留原文，并配中文解释。
- 示例和测试数据用明显虚构的人名（如 陈明、ESEMPIO FITTIZIO）。

## 5. 无障碍
- 所有可点的东西都用真正的 `<button>`、`<a>`、`<input>`、`<label>`；只有图标的按钮要加 `aria-label`。
- 文字对比度目标至少 4.5:1；颜色只用 §2.1 的变量，不能另取更浅的颜色。
- 新拟物边界已按 D44 添加普通描边、小字相对单位及当前项对比度调整，结果与实机限制见 §2.5 和 `docs/UI-D42-VALIDATION.md`；其余外观调整仍由用户决定。
- 错误不能只靠颜色表达，要同时有文字说明和红色边框。
- 系统字体放大后，问卷和参考件页仍然要能用。
