# 柔和新拟物视觉预览

按用户提供的 Claude 独立原型截图制作，聚焦姓名与出生资料这一屏。它已作为 D42 视觉基准接入正式应用；D44 同步了用户确认的描边、相对小字和当前步骤文字。不代替正式业务校验，规格见 `docs/UI-DESIGN.md`。

## 查看

- `index.html` 是无需外部依赖的单文件预览。
- 从仓库根目录运行 `node node_modules/vite/bin/vite.js designs --host 127.0.0.1 --port 4312`。
- 打开 `http://127.0.0.1:4312/soft-neumorphism/`。
- 普通、聚焦、报错三个按钮可切换状态；支持字段编辑、国家搜索、帮助弹窗和填写摘要。
- 所有资料都是明确虚构的演示值；不读写应用存储，不保存或提交资料。国家列表只提供 4 项；上一步和返回展示原型说明，下一步展示摘要，不模拟完整申请流程。

## 样式要点

- 保留暖米色和赤陶色。光源统一来自左上角。
- 输入框使用浅内阴影和D44 授权的 `--line` 1px 描边；聚焦或报错时只给该边框着色，不增加额外环，也不改变尺寸。
- 次要按钮微凸，按下转内凹。主按钮保留赤陶色实底。
- 主表单面板降低阴影对比；标题图标不额外嵌套浮雕底座。
- 错误用细边、图标和文字共同提示，取消厚重的整块提示背景。

本提案为展示新拟物方向，普通输入框边界较柔和。正式接入时需进一步验证高对比度模式、完整问卷和更大字体下的可读性。
